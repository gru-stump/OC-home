# OC-home v2 + 사이트 편집기 (admin)

> 본 배포는 **혜 [@hye0000_](https://x.com/hye0000_)** 님의 **갠홈 밀키트 전체 배포 - 03**을 기반으로,
> 코딩을 직접 입력하지 않고 **편집기를 통해 웹 홈페이지를 수정**할 수 있도록 해주는 배포입니다.

OC-home v2 밀키트에 **사이트 안 편집기**를 붙인 버전이에요.
`data.js` 를 열어 코드를 고치는 대신, 브라우저에서 **입력칸으로 편집하고 옆에서 바로 미리보기**를 보며 저장해요.

## 원본에서 달라진 점
| | 원본 | 이 버전 |
|---|---|---|
| 내용 수정 | `data.js` 를 직접 고쳐서 다시 올리기 | **`내사이트/#admin` 에서 입력칸으로 편집 → 저장** |
| 미리보기 | 없음 | **왼쪽 실시간 미리보기** + 모바일 전환 |
| 이미지 | 이미지 주소(링크)를 구해서 붙이기 | **편집기에서 [올리기]** (Firebase Storage) — 주소도 그대로 쓸 수 있어요 |
| 캐릭터 · 페어 추가 | 덩어리를 복사해서 붙여넣기 + 번호 고치기 | **[+ 추가 ▾] 에서 카드 종류 · 페어 인원을 골라 추가**, 순서를 바꾸거나 지워도 **번호가 자동 정리** |
| 색 | 색 코드 입력 | **색 선택기** |
| 방명록 | 구글 폼 + 시트 | **Firebase** (비밀글 / 답글 / 삭제를 사이트 안에서) |
| 처음 설정 | 코드 편집 | **`#setup` 설치 화면** (붙여넣기만) |

그 밖의 화면과 디자인은 원본 그대로예요. `data.js`, `style.css` 는 **원본 파일을 건드리지 않았어요.**

## 설치 순서 (약 30분)

### 1. 올리기
1. GitHub 에 새 저장소(Public)를 만들고 이 폴더의 파일과 폴더를 **전부** 올리기
   (`index.html`, `style.css`, `data.js`, `admin.js`, `site.config.js`, `images/`, `logs/`, `*.rules`)
2. [Vercel](https://vercel.com) → Continue with GitHub → 저장소 Import
   - **Framework Preset : Other**, 빌드 설정은 비워 두고 **Deploy**
   - 누구나 열려야 하니 **Settings → Deployment Protection** 에서 보호를 꺼 주세요.

### 2. Firebase 만들기
[Firebase 콘솔](https://console.firebase.google.com) → 프로젝트 추가
1. **Authentication → Sign-in method → Google** 사용 설정
2. **Authentication → 설정 → 승인된 도메인** 에 `내프로젝트.vercel.app` 추가
3. **Firestore Database → 데이터베이스 만들기** (프로덕션 모드)
4. **Storage → 시작하기** (이미지 업로드용. 요금제 안내를 확인하세요)
5. **⚙ 프로젝트 설정 → 일반 → 내 앱 → 웹 앱(`</>`)** 등록 → `firebaseConfig` 복사

### 3. 설치 화면에서 연결 (코드 안 열어도 돼요)
1. `https://내프로젝트.vercel.app/#setup` 접속
2. `firebaseConfig` 붙여넣기 + **관리자 이메일** 입력
3. **site.config.js 내려받기** → 저장소의 `site.config.js` 를 이 파일로 덮어쓰고 커밋
4. 화면에 나온 **Firestore 규칙 / Storage 규칙** 을 복사해 콘솔의 규칙 탭에 붙여넣고 **게시**
   (관리자 이메일이 자동으로 들어가 있어요)

### 4. 편집하기
`https://내프로젝트.vercel.app/#admin` → Google 로그인(관리자 이메일) → 편집 → **저장**

## 편집기 사용법
- **왼쪽 미리보기**: 입력하면 0.6초쯤 뒤 바로 반영돼요. 위쪽에서 화면(메인 / Character / Pair / Owner / Guest)을 고르거나 **모바일로 보기**.
  왼쪽 메뉴에서 항목을 누르면 미리보기도 그 화면으로 이동해요.
- **+ 추가 ▾** :
  - **캐릭터 목록** → 학생증 / 공연 티켓 / 수배지 / 직접 만든 카드 중 골라 추가
  - **페어 목록** → 2인 / 3인 / 4인 관계 중 골라 추가
  - **메인 메뉴** → 캐릭터 / 페어 / 오너 / 방명록 / 다른 사이트 링크
  - 카드 안의 **+ 항목 추가…** 로 빠진 칸(`pairImage`, `sdSize` 등)도 꺼낼 수 있어요.
- **번호 자동 정리** : 캐릭터 순서를 ↑↓ 로 바꾸거나 ✕ 로 지우면, 그 캐릭터가 들어간 **페어 멤버 · 리뷰(from/to) · 관계 링크**의 번호가 같이 고쳐져요.
  캐릭터를 지우면 그 캐릭터가 들어간 페어에서도 멤버와 리뷰가 정리돼요.
- **캐릭터 번호 칸** (멤버 / 리뷰 쓴 사람 / 받은 사람 / 관계 링크) 은 **이름을 보며 고르는 선택 상자**예요.
- **올리기** : 이미지 칸의 버튼으로 바로 업로드해요 (파일당 10MB 이하).
- **방명록 관리** : 비밀글 포함 전체 읽기, 답글, 삭제.
- **저장** : 방문자에게 반영돼요. **기본값으로** 를 누르면 저장된 설정을 지우고 `data.js` 값으로 돌아가요.

## 알아 두세요
- 편집기에서 한 번 저장하면 **저장된 값이 `data.js` 보다 우선**해요. `data.js` 를 직접 고쳤는데 안 바뀌어 보이면 **기본값으로** 를 눌러 주세요.
- `site.config.js` 의 연결 값과 관리자 이메일은 **공개돼도 되는 값**이에요. 실제 보안은 **Firestore/Storage 규칙**이 막아요.
- 설정이 아직 없으면 사이트는 원본처럼 동작하고, `#admin` 은 설치 화면을 보여줘요.
- 방명록은 설치가 끝나면 자동으로 Firebase 방식이 돼요. 예전 구글 폼 방식을 쓰려면 `data.js` 의 `guest.form.formLink` 를 채우면 그대로 쓸 수 있어요.
- **비밀글**은 방문자 화면에 **목록으로도 나오지 않아요** (오너만 `#admin → 방명록 관리` 에서 봐요). 구글 폼 방식처럼 "비밀글이에요" 자리 표시는 안 보여요.
- **TRPG 로그 파일**(`logs/…html`)은 `data.js` 의 `file` 칸에 위치를 적는 방식 그대로예요. 파일 자체는 저장소 `logs/` 폴더에 올려요.
- 방문자가 처음 열 때 저장된 설정을 받아 오느라 페이지가 한 번 다시 로드될 수 있어요.
- Storage 이미지 위치(리전)와 요금제는 콘솔 안내를 확인하세요. 한 번 정하면 바꿀 수 없어요.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 원본 + 설정 불러오기, Firebase 방명록, 편집기 연결 |
| `style.css`, `data.js` | **원본 그대로** (기본값) |
| `images/`, `logs/` | 원본의 SD 이미지, 로그 샘플 |
| `admin.js` | 편집기 · 미리보기 · 설치 화면 |
| `site.config.js` | 내 Firebase 연결 + 관리자 이메일 (`#setup` 이 만들어 줘요) |
| `firestore.rules`, `storage.rules` | 규칙 견본 (`#setup` 이 이메일을 넣어 줘요) |
